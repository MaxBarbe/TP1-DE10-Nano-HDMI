Les quatre photos de consommation correspondent aux releves du tableau du README principal.
Les etats ON/OFF ont ete confirmes par l’utilisateur. Les puissances du CSV sont
calculees par U × I, a partir des valeurs lisibles sur le testeur.

- IMG_0568.jpeg : SW0 ON.
- IMG_0566.jpeg : SW0 OFF.
- IMG_0572.jpeg : SW0 ON.

Montage declare : PC USB → UM25C → entree DC 5 V de la DE10-Nano.
Le resultat de 52,9 mJ/image concerne la plateforme a l’entree d’alimentation,
avec les pertes en aval du testeur. Les mesures sont des instantanes, sans
integration sur une duree commune ni correction des pertes du cable.
Voir ../README.md pour les calculs et leurs limites.
